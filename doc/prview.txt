==============================================================================
INTRODUCTION                                              *prview-introduction*

PRView browses open merge requests for the current repository's GitLab project.
The fzf-lua picker shows the complete GitLab-provided diff for the focused
merge request. PRView does not change local repository or GitLab state.

Required: glab and fzf-lua. Optional: delta for colored diff previews.
Authenticate GitLab requests with GITLAB_TOKEN or `glab auth login`. PRView
does not handle tokens itself.

==============================================================================
SETUP                                                            *prview-setup*

>lua
    require('prview').setup()
<

Setup is idempotent. Dependency checks and external processes are deferred
until the command is invoked.

==============================================================================
CONFIGURATION                                      *prview-configuration*

The picker opens fullscreen by default. Pass per-picker fzf-lua options under
`fzf_lua`; nested values override PRView's defaults. For example, to use a
smaller window:

>lua
    require('prview').setup({
        fzf_lua = {
            winopts = {
                fullscreen = false,
                width = 0.9,
            },
        },
    })
<

PRView retains its diff previewer, required selection fields,
default and CTRL-O actions, and close cleanup. Additional fzf-lua actions, a
tab-stop override, and a `winopts.on_close` callback are supported.

==============================================================================
:PRView                                                          *:PRView*

Opens the open merge request picker. Highlight a merge request to preview its
complete, scrollable GitLab diff. Each entry shows its IID, latest-update time, full title, and author as
`!IID (updated) title <@author>`, colored like fzf-lua git commits, under the
`MR Number (Last Updated Time) Title <Author>` header. Recent updates appear as
relative time; older updates appear as a calendar date. The preview shows the
diff. Delta formats and colors the diff when available; raw diff syntax is the
fallback. Delta's formatted file and hunk headers are preserved. Press CTRL-O
to open the highlighted merge request in GitLab without closing the picker.
ENTER does not close or replace the picker.
